## 💻 Philosophy

This repository is focused on **learning by building**.

The goal is not to memorize Python syntax, but to understand:

* Why a concept exists
* When it should be used
* How it is used in real software
* How it connects to larger systems
* How to write clean and maintainable code

As I progress, the projects will become increasingly complex and closer to real-world software and AI applications.
